# EduTrack — Student Performance Analysis

A responsive dashboard for analyzing student performance using HTML, CSS, and vanilla JavaScript.

## Features
- Dashboard overview with total students, average GPA, top performer, and at-risk count
- Performance chart comparing class averages and top performers
- Grade distribution visualization
- Top-performer table and recent activity feed
- Student directory with live search
- Add student records in the current browser session
- Reports summary and settings information
- Responsive layout for desktop, tablet, and mobile

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

No build tools or dependencies are required. Google Fonts are loaded online; the system font will be used if offline.

## Deploy with GitHub Pages
1. Create a public repository, for example `student-performance-analysis`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the published URL to appear.

## Important note
This is a front-end portfolio demo using illustrative sample data. It has no backend, authentication, database, or permanent storage. Student records added in the UI only last for the current page session. Do not use real or sensitive student data without adding appropriate security, access controls, and a compliant backend.
